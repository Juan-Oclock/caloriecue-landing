# Calorie Counting Made Simple

Editable source for the published 15-page A4 ebook. Open the HTML through a local static server; Google Fonts supplies Merriweather and Figtree. The source retains editable text, tables and SVG graphics.

Print on A4 portrait with margins None, background graphics enabled, browser headers/footers disabled, and scale 100%. The release PDF lives at assets/pdfs/caloriecue-cheat-sheet.pdf. The website prebuild copies that exact asset to the public download and static API response; email attachments read the same file.

food-reference-80-items.json is the curated table; food-reference-audit.json records the row-level USDA FDC records, portion weights, calculations and four label/recipe examples. The public CSV supplies accessible source details linked from the PDF. Estimates are representative, not universal product values.

See Production Notes.md for source URLs, editorial changes, and image-resolution details. The cover is approximately 188 ppi at full A4 width.
